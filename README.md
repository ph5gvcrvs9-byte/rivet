# Rivet
a pomodoro timer with a tamagotchi pet cat that stays happy as long as you focus enough for the day!

### why??
i have been struggling to focus this past few days and something that helped me with focusing in the past is using the pomodoro technique. i browsed through different pomodoro websites but most of them seems boring and i wanted something that is more fun and just lives inside my screen. then light bulb! since i was learning swift anyway.. and i haven't made a macos app.. WHY NOT JUST MAKE MY OWN POMODORO APP!

### features
- [x] pomodoro timers: focus time, break time, long break time
- [x] a cat that i drew that is shows emotions based on what you are doing
- [x] notification when time is up!
- [x] cat name customization
- [ ] settings

### how to use
1. open the testflight link
2. download rivet
3. look to your toolbar and click on the paw icon "🐾"
4. click on the play button "▶️" to start the timer
5. now, focus!

### tech stack
i used swiftui in xcode. uploaded it on testflight too for demo
